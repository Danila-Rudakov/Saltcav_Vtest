# Математическая модель выщелачивания горизонтального канала в блоке NaCl

Модель лабораторной установки (на поверхности или на заданной глубине до 2800 м). Блок каменной соли с горизонтальным каналом диаметром
2–3 мм; насос подаёт в один торец дистиллят (или рассол), из другого выходит рассол. Два
варианта установки:

* **канал в целом блоке** (`setup: channel`);
* **полуканал у окна** (`setup: window`): блок разрезан вертикальной плоскостью через ось
  канала, к срезу на эпоксидной смоле приклеено оргстекло. Видна половина каверны.

Код: модель сечения — `src/saltcav/leaching/section.py` (геометрия — `geometry/section.py`), простая
модель с круглым сечением — `leaching/axisym.py` (геометрия — `geometry/channel.py`), глубина:
трубки, давление, ползучесть — `leaching/depth.py`, конфигурация — `core/lab_config.py`. Свойства воды и рассола, схема переноса и плотностная устойчивость взяты из saltcav (автор — Sergei Kizred).

## 1. Допущения

1. Соль однородная, чистый NaCl, плотность ρ_s. Трещины и границы зёрен не учитываются.
2. Температура опыта постоянна (охлаждение стенки теплотой растворения оценивается, раздел 5).
   Свойства: растворимость C_s(T) и плотность рассола ρ(c, T) — таблицы CRC; вязкость
   рассола μ(c, T) — Kestin и др. (1981); диффузия D(T) — по Стоксу—Эйнштейну.
3. Течение ламинарное (Re ≈ 1–200). Время прохода воды через канал (минуты) много меньше
   времени изменения формы (часы), поэтому на каждом шаге течение квазистационарно.
4. Растворение — последовательные стадии: реакция на поверхности и массоотдача (раздел 5).
   По умолчанию реакция считается быстрой (транспортный контроль); константа реакции
   задаётся параметром, когда будет взята из литературы или опыта.
5. Поле скоростей в сечении не рассчитывается (это не CFD). Свободная конвекция
   учитывается через корреляции массоотдачи и через плотностное расслоение рассола.
6. Окно из оргстекла не растворяется и не пропускает соль; шов не протекает.

## 2. Геометрия

Ось канала x ∈ [0, L] горизонтальна, вход при x = 0. Сечение задаётся расстоянием от оси до
стенки r(θ, x, t), где θ — угол от вертикали вверх: θ = 0 потолок, θ = π/2 бок, θ = π дно.
Начальное условие: r(θ, x, 0) = d₀/2.

Задача с гравитацией симметрична относительно вертикальной плоскости через ось, поэтому
считается половина сечения θ ∈ [0, π]:

| | канал в блоке | полуканал у окна |
| --- | --- | --- |
| расход через половину | Q/2 | Q |
| плоскость θ = 0…π | плоскость симметрии | окно (стенка без растворения) |
| смоченный периметр половины P | дуга стенки | дуга стенки + высота сечения H |
| объём и масса каверны | 2 × половина | 1 × половина |

Площадь половины сечения A = ½∫r²dθ, гидравлический диаметр D_h = 4A/P, высота сечения
H = r(0) + r(π).

**Вывод для опыта.** При расходе через окно Q_окно = Q/2 скорость в половине та же, что в
целом канале. Тогда половина каверны у окна повторяет половину целого канала; отличие даёт
только трение о стекло (меньше D_h). Модель считает это отличие: сравнение — два расчёта, канал при Q и окно при Q/2.

## 3. Растворение стенки

Поток соли со стенки, кг/(м²·с):

    j = k · (C_s − c),

где c — концентрация рассола у этого участка стенки. Стенка отступает по нормали со
скоростью V = j/(ρ_s − C_s) (условие Стефана: растворившаяся соль замещается раствором, поэтому
граница отступает в ρ_s/(ρ_s − C_s) ≈ 1,17 раза быстрее, чем при V = j/ρ_s; параметр
`stefan_condition: false` возвращает V = j/ρ_s). Для формы r(θ, x) это уравнение Гамильтона—Якоби:

    ∂r/∂t = V · √(1 + (∂r/∂θ / r)² + (∂r/∂x)²).

Граничные условия: при θ = 0 и θ = π — зеркальные (∂r/∂θ = 0; в режиме `setup: full` вместо
них — периодическое замыкание θ = 2π ≡ 0 на всём контуре 0…360°, без допущения о симметрии); на торцах x = 0, L —
∂r/∂x = 0.

## 4. Массоотдача: смешанная конвекция

Коэффициент массоотдачи складывается из вынужденной и свободной конвекции по правилу
Черчилля:

    k = (k_вын³ + k_св³)^(1/3).

**Вынужденная (ламинарное течение, задача Грэца—Левека):**

    Gz = u·D_h²/(D·x),   u = Q_половины / A,
    Sh = max(3,66;  1,077·Gz^(1/3)) · sh_mult,   k_вын = Sh · D / D_h.

1,077·Gz^(1/3) — локальное решение Левека для развивающегося профиля концентрации у входа,
3,66 — предел Грэца для развитого профиля при постоянной концентрации на стенке.

**Свободная.** Рассол у стенки насыщен и тяжелее ядра на Δρ = ρ(C_s) − ρ(c):

* потолок (тяжёлый слой под горизонтальной поверхностью неустойчив, срывается плюмами):

      k_пот = 0,15 · (g·(Δρ/ρ)·D²/ν)^(1/3) · roof_mult    (Sh = 0,15·Ra^(1/3));

* боковая стенка (опускающийся ламинарный пограничный слой высоты H):

      k_бок = 0,59 · (D/H) · Ra_H^(1/4) · wall_mult,   Ra_H = g·(Δρ/ρ)·H³/(ν·D);

* дно: слой тяжёлого рассола устойчив, k_св = 0.

Между ними k_св меняется линейно по n_z — вертикальной составляющей единичной нормали
«в соль» (n_z = 1 потолок, 0 бок, −1 дно).

**Критерий режима** — отношение свободной и вынужденной конвекции:

    Gr/Re² = g · (Δρ/ρ) · D_h / u².

Для круглого канала это g·(Δρ/ρ)·π²·d⁵/(16·Q²): растёт как d⁵, поэтому по мере роста
канала свободная конвекция быстро становится главной.

## 5. Химия растворения NaCl

**Реакция и равновесие.** NaCl(тв) ⇄ Na⁺(р-р) + Cl⁻(р-р). Равновесие — насыщенный раствор,
C_s(T) по таблице растворимости CRC (при 20 °C 26,41 % масс., 317 г/л).

**Стадии.** Растворение идёт последовательно: (1) реакция на поверхности — уход ионов из
кристаллической решётки, j = k_р·(C_s − c_ст); (2) диффузия через концентрационный
пограничный слой, j = k_масс·(c_ст − c); (3) унос рассола конвекцией. Исключая концентрацию
на стенке c_ст:

    j = (C_s − c) / (1/k_масс + 1/k_р),    Da = k_масс / k_р.

Da ≪ 1 — транспортный контроль (скорость растёт с расходом как Q^(1/3)), Da ≫ 1 —
кинетический (от расхода не зависит, сильно зависит от температуры). Кинетика растворения
галита: Alkattan, Oelkers, Dandurand, Schott (1997), Chem. Geol. 137, 201–219 (вращающийся
диск, 25–80 °C; скорость линейна по степени насыщения; следы Co, Cr, Cd, Pb её снижают).
Константы реакции из полного текста этой работы вносятся в `k_surface_m_s`.

**Свойства рассола** (функции концентрации; для пограничного слоя — при (c + C_s)/2):

| Свойство | Источник | Точность |
| --- | --- | --- |
| C_s(T), ρ(w, T) | CRC Handbook (таблицы saltcav) | табличная |
| μ(m, T): log₁₀(μ/μ_w) = A(m) + B(m)·log₁₀(μ_w/μ_w(20 °C)), A = Σaᵢmⁱ, B = Σbᵢmⁱ | Kestin, Khalifa, Correia (1981), J. Phys. Chem. Ref. Data 10, 71 | ±0,5 % (20–150 °C, 0–6 моль/кг) |
| μ_w(t): log₁₀(μ_w/μ_w(20 °C)) = Σαᵢ(20 − t)ⁱ/(96 + t) | там же (Kestin, Sokolov, Wakeham, 1978) | |
| D(T) = D₂₅·(T/298)·μ_w(25)/μ_w(T), D₂₅ = 1,61·10⁻⁹ м²/с | saltcav | D меняется с концентрацией в пределах 1,47–1,61·10⁻⁹ (Rard, Miller 1979, по вторичному источнику): ±3 % в k ∝ D^(2/3) |
| ΔH растворения = +3,88 кДж/моль | Parker (1965), NBS, бесконечное разбавление | |

Вязкость рассола входит в свободную конвекцию (Ra ∝ 1/ν, Sc = ν/D: 713 для воды и 1176
для насыщенного рассола при 20 °C), в вынужденную — нет (Gz = u·D_h²/(D·x)).
Формула вязкости сверена с таблицами Kestin и др. в 6 точках (0,5–6 моль/кг, 20 и 25 °C):
расхождение ≤ 0,3 мкПа·с (тест `test_brine_viscosity_matches_kestin_tables`).

**Объём раствора.** 1 г соли освобождает в блоке 1/ρ_s = 0,463 см³, а объём раствора растёт
лишь на 0,29–0,40 см³ (по таблице плотности). Расход вдоль канала считается из баланса массы
раствора: Q_i = (ρ_{i−1}Q_{i−1} + ṁ_i − d(V_iρ_i)/dt)/ρ_i, поэтому расход на выходе отличается
от подачи насоса. Баланс соли выполняется точно; баланс воды — с точностью ~0,5 % (объём
смешения рассолов разной концентрации в неизменном объёме ячейки).

**Тепло.** Растворение поглощает тепло, стенка охлаждается. Оценка сверху (тепло подводится
только теплопроводностью соли λ, отвод рассолом не учтён):
ΔT ≈ (j·ΔH/M)·r·ln(R/r)/λ. В примерах ΔT ≤ 1,4 К: растворимость меняется на 0,01 %/К,
вязкость — на 2,4 %/К, то есть влияние на скорость растворения до ~3 %. Значение
λ = 6 Вт/(м·К) — оценка для каменной соли, уточнить по справочнику (Clauser, Huenges, 1995).

**Не учтено:** примеси (гималайская соль содержит сульфаты, Ca, Mg, Fe и нерастворимые
включения), зависимость D от концентрации, давление (~0,1 МПа).

## 6. Установка на глубине: давление, температура, трубки

Ту же установку можно «опустить» на глубину H (параметр `depth_m`, до 2800 м). Насос на
поверхности подаёт воду по подающей трубке вниз; рассол поднимается на поверхность по
отводящей трубке и вытекает при атмосферном давлении — второго насоса нет (сообщающиеся
сосуды). Код: `src/saltcav/leaching/depth.py`, свойства под давлением — `src/saltcav/core/brine.py`.

**Давление и температура в каверне.**

    p_каверны ≈ p_атм + ρ_воды·g·H   (свойства рассола считаются при этом давлении),
    T = T_поверхности + градиент·H/100   (если задан `geothermal_gradient_c_per_100m`).

Насос добавляет к давлению разницу столбов рассола и воды (до ~2,4 МПа на 1200 м) и трение;
на свойства это влияет меньше чем на 0,1 %, поэтому для свойств берётся гидростатика воды,
а точное давление считается отдельно (ниже). Вода, опускаясь по трубке часами, успевает
прогреться до температуры пород.

**Как давление меняет свойства** (все поправки сверены с таблицами Kestin и др., 1981):

| Свойство | Зависимость от давления | Источник | На 1200 м (≈ 12 МПа), 20 °C |
| --- | --- | --- | --- |
| растворимость | m_s(p) = m_s(0,1 МПа)·(1 + 2,5·10⁻⁴·(p − 0,1)), p в МПа | Sawamura и др. (2007): 6,61 моль/кг при 0,3 ГПа; совпадает с термодинамической оценкой по V̄_NaCl < V_галита | C_s +0,6 % |
| плотность | ρ(p) = ρ_CRC(w, T)·v(0,1)/v(p), v — удельный объём по Rowe, Chou (1970) | Rowe, Chou (1970), J. Chem. Eng. Data 15, 61; в записи Kestin и др. (1981), ур. (11a)–(14) | вода +0,56 %, насыщ. рассол +0,36 % |
| вязкость | μ = μ⁰·(1 + β·p), β = β_s^E·β*(m/m_s) + β_w, p в ГПа | Kestin и др. (1981), ур. (1), (6)–(10) | насыщ. рассол +1 %, вода −0,5 % |
| диффузия | D ∝ T/μ_воды(p) (Стокс—Эйнштейн) | saltcav | +0,5 % |

Давление сжимает воду сильнее, чем рассол, поэтому разница плотностей Δρ, которая движет
свободной конвекцией, немного уменьшается; растворимость немного растёт. Итог на 1200 м —
изменение объёма каверны около +1 %. **Если задан геотермический градиент, главное влияние
глубины — через температуру** (при 2,5 °C/100 м на 1200 м — 50 °C: диффузия вдвое быстрее,
вязкость вдвое меньше, объём каверны в примере +21 %).

**Трубки и насос** (поршневое вытеснение в отводящей трубке, ламинарное течение):

    p_каверны = p_атм + ρ_отв·g·H + Δp_тр,отв,
    p_насоса (избыточное) = (ρ_отв − ρ_под)·g·H + Δp_тр,под + Δp_тр,отв,
    Δp_тр = 128·μ·H·Q/(π·d⁴)  (Хаген—Пуазейль).

ρ_отв — средняя плотность в отводящей трубке: вначале там вода, её «поршнем» вытесняет
рассол из каверны. Объём трубки (4 мм × 1200 м ≈ 15 л) много больше каверны, поэтому рассол
доходит до поверхности только через V_трубки/Q (≈ 12 ч при 20 мл/мин): **замеры
концентрации на поверхности запаздывают** на это время, а давление насоса растёт по мере
заполнения трубки рассолом до (ρ_рассола − ρ_воды)·g·H ≈ 2,4 МПа. Если насос остановить,
тяжёлый столб рассола потечёт обратно — самотёком рассол не поднимается.

**Горное давление и ползучесть.** Если блок — часть массива, на него давит σ = ρ_пород·g·H.
Сужение полости — оценка для цилиндрической полости в бесконечной среде со степенной
ползучестью (закон BGRa из saltcav, плоская деформация):

    ṙ/r = (√3/2)^(n+1) · A·exp(−Q/RT) · (2·(σ − p_каверны)/n)^n,  A = 0,18 сут⁻¹, n = 5, Q = 54 кДж/моль.

На 1200 м за часы опыта — порядка 10⁻⁸ радиуса: пренебрежимо (важно для камер, живущих годами).

**Сравнение по глубинам** (`leaching/depth.py`, `depth_study`): тот же опыт на 5 глубинах от 0 до
max(1200 м, заданная): объём, насыщение на выходе, форма, давление насоса.

## 7. Перенос рассола

Канал разбит вдоль x на n ячеек, каждое сечение — на n_θ клиньев (секторов) между лучами
θ_j и θ_{j+1}; в клине концентрация c_ij. Баланс соли:

    ∂(A·c)/∂t + ∂(Q·c)/∂x = ∮ j dl.

Вдоль x — неявная схема против потока (как в saltcav): каждый клин течёт на своей высоте,
расход делится между клиньями пропорционально их объёму. На входе c = c_вх (0 —
дистиллят). Расход на выходе меньше подачи на скорость роста объёма: Q_вых = Q − dV/dt.

В сечении:

* **Gr/Re² < ri_crit** — вынужденное течение перемешивает сечение, c одинакова по θ;
* **Gr/Re² ≥ ri_crit** — расслоение. Насыщенный пограничный слой стекает вниз,
  перемешиваясь на пути: соль со стенки клина распределяется по клиньям не выше его центра
  пропорционально объёму («заполняющийся объём», filling box); избыток сверх C_s
  поднимается выше. Затем профиль приводится к устойчивому: концентрация не убывает сверху
  вниз (изотоническая регрессия saltcav, масса сохраняется).

В итоге пресная вода идёт по потолку, у дна копится насыщенный рассол, и каверна растёт
вверх.

## 8. Численная схема

* Движение стенки — монотонная схема Годунова для √(1 + p²), явная по времени.
* Шаг по времени: условие Куранта, рост радиуса ≤ 2 % за шаг, рост объёма ≤ ½ подачи,
  запрет пересыщения сечения.
* Растворённая соль считается как ρ_s·ΔV: баланс «растворено + пришло = вынесено +
  осталось» выполняется до ошибки округления (~10⁻¹⁴ г).
* Расчёт останавливается, когда канал доходит до грани блока (`max_radius_mm`).

## 10. Параметры для калибровки по опытам

| Параметр | Что меняет | Чем измерить |
| --- | --- | --- |
| `sh_mult` | вынужденная массоотдача | c_вых(t) при большом расходе, пока канал узкий |
| `roof_mult` | рост потолка | высота каверны через окно (фото во времени) |
| `wall_mult` | рост боков | ширина каверны через окно |
| `ri_crit` | когда начинается расслоение | момент, когда сечение перестаёт быть круглым |
| `k_surface_m_s` | скорость реакции на поверхности | серия опытов с разными расходами: зависит ли скорость от Q |

Опыт с окном даёт форму каверны во времени без разрушения блока: фото через оргстекло с
масштабной линейкой. Сравнение с моделью — по рядам результата (`times`, `outlet_concentration`, `volume`, `radius`).

## 11. Этапы процесса и критерии их начала

Форма каверны определяется распределением скорости стенки V = k·(C_s − c)/(ρ_s − C_s) по
контуру: где больше k и где вода у стенки менее насыщена, там стенка уходит быстрее.
Критерии ниже позволяют разбить результат расчёта (`SectionResult`) на этапы:

| Этап | Критерий начала | Что происходит с формой |
| --- | --- | --- |
| 1. Вынужденная конвекция | Gr/Re² < ri_crit | сечение растёт кругом; у входа быстрее (C_s − c больше) |
| 2. Свободная конвекция и расслоение | Gr/Re² = g·(Δρ/ρ)·D_h/u² ≥ ri_crit | тяжёлый рассол стекает вниз, пресная вода по потолку |
| 3. Потолок под свободной конвекцией | k_пот > k_вын | потолок растёт быстрее всего; k_пот не зависит от размера, k_вын ∝ 1/D_h падает |
| 4. Сечение некруглое | подъём потолка > 1,5 × опускания дна | форма вытягивается вверх |
| 5. Дно защищено рассолом | c у дна ≥ 0,9·C_s | V_дно → 0, каверна растёт вверх и в стороны над рассолом |
| смена режима насоса | новая ступень | k_вын ∝ Q^(1/3), Gr/Re² ∝ 1/Q² |

Так как Gr/Re² ∝ d⁵/Q², при расходе в единицы мл/мин этапы 2–3 наступают уже в узком
канале (в примере сразу), а при десятках мл/мин — позже, когда канал подрастёт.
Вклад каждого механизма считается как разность потоков: вынужденная —
k_вын·(C_s − c), свободная — (k − k_вын)·(C_s − c).

## 12. Ограничения

* Корреляции массоотдачи — для простых поверхностей; для каверны их уточняют множители.
* Расслоение — мгновенное упорядочение по плотности, без поля скоростей; струя из
  входной трубки отдельно не моделируется.
* Глубина: давление для свойств — гидростатика воды (без добавки насоса, < 0,1 % в свойствах); трубки — поршневое вытеснение без размывания фронта; температура в трубке не рассчитывается (вода считается прогретой до температуры пород); ползучесть — оценка.
* Блок однородный; для окна не учитываются протечки шва и растворение вдоль стекла
  сверх зеркальной картины.
